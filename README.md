## 作り方

### 1. 野菜の下準備
1. **玉ねぎ**をくし切りにします。
2. **にんじん**と**じゃがいも**は一口大の乱切りにし、耐熱容器に入れます。電子レンジ（700W）で約3分、柔らかくなるまで加熱しておきます。

### 2. 玉ねぎを炒める
3. 鍋に**サラダ油**、**にんにく**、**赤唐辛子**を入れて弱火で熱し、油に香りをじっくり移します。
4. にんにくに火が通り始めたら**玉ねぎ**を加え、全体にきれいな焼き色がつくまでしっかりと加熱します。

### 3. スープのベース作りと煮込み
5. 玉ねぎに焼き色がついてきたら、**水（分量外）** を加えて強火にし、沸騰するまで熱します。
6. 沸騰したら、レンジ加熱しておいた**にんじん**を加えます。
7. 続けて、**コンソメ**、**ローリエ**、**カットトマト缶**を加え、弱火〜中火で煮込みます。

### 4. お肉の旨味を閉じ込める（別フライパン）
8. 別のフライパンに**肉**を入れ、表面に火が通るまで炒めます。
9. 表面に火が通ったら**赤ワイン**を回し入れ、蓋をして蒸し煮にします。
10. ワインの水気が減ってきたら蓋を開け、お肉に完全に火を通します。火が通ったら、旨味ごと先ほどの煮込み鍋に移します。

### 5. 仕上げ
11. 鍋にレンジ加熱しておいた**じゃがいも**を加え、少し煮込みます。
12. 全体に火が通ったら一度**火を止め**、**カレールー**を割り入れます。
13. ルーが完全に溶けるまでよく混ぜ合わせ、弱火でひと煮立ちさせたら完成です！
